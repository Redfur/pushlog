## [1.0.3] - 2026-03-29

### Added

- Полное удаление типа упражнения с карточки: подтверждение в диалоге, удаление типа, всех подходов по нему и дневной цели в IndexedDB, переход на главную.

## [1.0.2] - 2026-03-29

### Added

- Экран ошибки маршрута: реализован компонент RouteErrorBoundary, который автоматически перезагружает страницу при ошибке загрузки чанка (например, после деплоя новой версии).
- Локализация системных ошибок роутера. Тексты ошибок и кнопки в boundary теперь переводятся через i18n.
- Скелетон-загрузчик для экрана статистики с поддержкой локализации ("Загрузка статистики").

### Changed

- Разделение страниц статистики и упражнения на отдельные чанки для оптимизации загрузки и работы lazy loading.
- Улучшена обработка ошибок загрузки чанков и отображения fallback при отложенной загрузке.

### Fixed

- Исправлен недочёт с повторной загрузкой страницы при ошибке подгрузки после деплоя (chunk load error) — теперь повторная перезагрузка не зацикливается.
- Мелкие улучшения UI скелетона при загрузке данных на странице статистики.
