# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). В заголовке версии **без** префикса `v` (например `1.2.3`); в git тег задаётся с префиксом: `v1.2.3`.

Заметные изменения поведения и UX (новые сценарии, изменения экранов, хранилища под пользовательские действия) фиксируйте в разделе **[Unreleased]** в том же изменении, что и код — чтобы история релизов оставалась полной.

## [Unreleased]

### Added

- Pre-commit через Lefthook

### Changed

- Экран дня: навигация по дате в той же **PageHeader** (`centerContent`), что и на остальных экранах — единая высота и стиль липкой шапки.
- Шапка экрана (**PageHeader** и др.) и **ScreenBody** перенесены в **`shared/layout`** (`@/shared/layout`); слайс `widgets/page-header` удалён — виджеты импортируют только `shared`, без перекрёстных зависимостей между виджетами. **ScreenBody** задаёт единые отступы и варианты для экрана / скелетона.
- Шапка экрана (**PageHeader**) и блок навигации по дням при прокрутке прилипают к верху (`sticky`), с полупрозрачным фоном и размытием; общие классы — **STICKY_PAGE_HEADER_SURFACE**. Верхний отступ внутри полосы (`pt-4 lg:pt-6`), у контейнера в `AppShell` на `lg` — `lg:pt-0`, нижний `lg:pb-2`.
- Главная: переход «День и календарь» в шапке — кнопка-иконка календаря без подписи (`aria-label` и подсказка при наведении сохраняют текст).
- Кнопка «назад» в шапке (**PageHeaderBackLink**): стиль без рамки (`ghost`, крупнее `ChevronLeft`), чтобы не совпадать с кнопками предыдущего/следующего дня (`outline`).
- Карточка упражнения: в шапке кнопка «назад» на главную; «Подробная статистика» и «Редактировать» в меню «ещё» (`DropdownMenu`).
- Единая шапка экрана (`PageHeader` / `PageHeaderBackLink`): согласованный заголовок, опционально «назад» слева и действия справа; на создании и редактировании упражнения дублирующие кнопки «на главную» / «к упражнению» в форме убраны в пользу шапки. Экран дня по-прежнему с **DayNavigation** без этого виджета.
- Внутренний рефакторинг: крупные UI-файлы разбиты на отдельные компоненты и модули (навигация, настройки, статистика, карточка упражнения, редактор типа и т.д.) без изменения поведения приложения.
- Главная: список активных упражнений убран; навигация к типу только через карточки «Сегодня» по каждому упражнению. В той же сетке добавлена отдельная карточка «Добавить упражнение» (пунктирная рамка). Блок архивных типов по-прежнему под быстрым вводом (HomeArchivedExercisesSection).
- Создание и редактирование упражнения: дневная цель задаётся в той же форме, что имя, иконка и цвет. На `/exercises/new` поле цели необязательно; после создания типа цель сохраняется при заполнении. На `/exercises/:id/edit` тип и цель сохраняются одной кнопкой «Сохранить»; пустое поле цели при существующей цели сбрасывает её. Для архивного типа цель по-прежнему только в виде подсказки без редактирования. Компонент ExerciseDailyGoalEditor заменяет прежний **ExerciseGoalFields с отдельным сохранением цели.

### Fixed

- Исправлено добавление подходов после создания первого упражнения

## [1.0.2] - 2026-03-29

### Added

- Экран ошибки маршрута: реализован компонент RouteErrorBoundary, который автоматически перезагружает страницу при ошибке загрузки чанка (например, после деплоя новой версии).
- Локализация системных ошибок роутера. Тексты ошибок и кнопки в boundary теперь переводятся через i18n.
- Скелетон-загрузчик для экрана статистики с поддержкой локализации ("Загрузка статистики").

### Changed

- Разделение страниц статистики и упражнения на отдельные чанки для оптимизации загрузки и работы lazy loading.
- Улучшена обработка ошибок загрузки чанков и отображения fallback при отложенной загрузке.

### Fixed

- Исправлен недочёт с повторной загрузкой страницы при ошибке подгрузки после деплоя (chunk load error) — теперь повторная перезагрузка не зацикливается.
- Мелкие улучшения UI скелетона при загрузке данных на странице статистики.
