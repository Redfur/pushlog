# Расширяемость и этапы развития

## 1. MVP

- IndexedDB + Zustand, один тип упражнения (отжимания).
- Главный экран: QuickAddPanel (+10, +20, repeat last), список за день, дневной прогресс (в т.ч. к цели при её наличии).
- Экран статистики: totals, averages, best day; настройка дневной цели; графики за 7/30 дней (повторения и подходы по дням); heatmap за 26 недель.
- Удаление подхода, базовая обработка ошибок storage.
- PWA: `site.webmanifest` (`start_url`, `scope`), Service Worker и precache через `vite-plugin-pwa` (офлайн после первой загрузки).

## 2. Улучшение UX

- Undo после добавления/удаления.
- Анимации и skeleton при гидрации.
- Явный выбор timezone / отображение «дня».
- Оптимизация холодного старта и размера бандла.

Реализация и детали UI: [spec/ui.md](ui.md) (навигация на десктопе, ленивый `/stats`, toasts, гидрация, timezone).

## 3. Геймификация

- Стрик (правила «не пропустить день») и отображение стрика в UI (счётчик уже считается в агрегатах).
- Расширения heatmap (диапазоны, год) при необходимости.
- Достижения (опционально, минимально).

## 4. Backend + sync

- Аккаунт, синхронизация между устройствами.
- Конфликт-резолвинг (например, по `updatedAt`/операционным логам).
- `ApiStorageAdapter` или слой sync поверх существующего store.

## 5. Расширение (типы упражнений)

- UI выбора типа, справочник `ExerciseType`.
- Раздельная статистика и цели по типам.
- Возможные единицы: время, вес (вне MVP).
