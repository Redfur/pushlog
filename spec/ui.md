# UI спецификация

## Навигация (MVP)

- Три раздела: **День** (лог за выбранный календарный день + ввод), **Статистика**, **Настройки**.
- Переключение: **нижняя навигация** на узких экранах (`lg` ниже); на **`lg` и шире** — фиксированная **левая колонка** (~64 tailwind units) с теми же пунктами (День / Статистика / Настройки), нижняя панель скрыта. Контент и навигация выровнены по одной вертикальной колонке: оболочка `mx-auto`, `max-w-3xl` (на экране статистики до `max-w-4xl` для графиков и heatmap), горизонтальные отступы `px-4 sm:px-6`.
- Предпочтение на мобилке — крупные зоны нажатия для скорости.
- **Маршруты дня:** `/day/today` и `/day/yesterday` (алиасы), `/day/YYYY-MM-DD` — отдельная «страница» дня; `/` перенаправляет на `/day/today`.
- **Маршрут статистики** `/stats` подключается **лениво** (`React.lazy` + `Suspense`), чтобы тяжёлые зависимости (Recharts, виджет статистики) не попадали в первый чанк; при загрузке показывается скелетон, согласованный с сеткой экрана.
- **Маршрут настроек** `/settings` также **ленивый** (отдельный чанк); скелетон при загрузке.

## Навигация по дням (DayNavigation)

| Аспект | Описание |
|--------|----------|
| Ответственность | Переход к предыдущему/следующему дню; выбор даты кликом по **заголовку даты** — Popover + календарь shadcn (`Calendar` + `react-day-picker`), чтобы одинаково работало на десктопе и в тач-интерфейсе. |
| Календарь | У дат, в которые есть хотя бы одна запись (по `dayKey` в store), под числом показывается **точка**; пустые дни без точки. |
| Поведение | Следующий день недоступен, если он позже сегодня. Возврат «на сегодня» — через нижнее меню (домой). |

## Главный экран

Состав: **QuickAddPanel**, **DaySetsList**, **DayProgress** (возможна композиция в `widgets/main-screen`).

### QuickAddPanel

| Аспект | Описание |
|--------|----------|
| Ответственность | Минимум шагов для добавления подхода; пресеты из конфига, **пользовательские быстрые значения** (localStorage), поле своего числа в одном ряду с кнопками, повтор последнего. |
| Содержимое | Кнопки **+10**, **+20**; **поле ввода** в стиле кнопки (outline) — Enter / «ввод» на мобильной клавиатуре добавляет подход; после успешного ввода число сохраняется как **быстрая кнопка** (кроме совпадений с дефолтными пресетами), не более **5** штук в `localStorage`; при добавлении шестого **вытесняется** самое раннее сохранённое (FIFO). Кнопка **«Как в прошлый раз»**. Пользовательские кнопки можно **удалить** (иконка). |
| Поведение | Тап по +N вызывает `addSet` с `reps: N` и **выбранным `dayKey`**. После успешного добавления — **тост с «Отменить»** (удаление только что созданной записи по `id`). Repeat last: последний подход за **этот день**; если в дне пусто — последний глобально для типа по умолчанию; если истории нет — кнопка без эффекта. |
| Edge | Debounce/loading state на кнопках 150–300 ms при необходимости, чтобы отсечь двойные тапы. |

### Список подходов за сегодня (DaySetsList)

| Аспект | Описание |
|--------|----------|
| Ответственность | Показать все `Set` за текущий `dayKey`. |
| Отображение | Время (локальное) или порядковый номер; число повторений; опционально иконка типа (MVP — один тип). |
| Поведение | Свайп или кнопка «удалить» на строке → `removeSet(id)`; подтверждение не обязательно — после удаления показывается **тост с действием «Отменить»** (восстановление строки через `restoreSet`). |
| Пустое состояние | Короткий текст + те же быстрые кнопки в фокусе. |

### Дневной прогресс (DayProgress)

| Аспект | Описание |
|--------|----------|
| Ответственность | Сумма `reps` за день; при наличии **Goal** (настраивается в **Настройках**) — прогресс-бар и fraction «35 / 50». |
| Поведение | Обновляется синхронно после мутации store. |

## Экран настроек

Маршрут `/settings`, виджет `widgets/settings-screen`.

| Блок | Описание |
|------|----------|
| Тема | Режимы: системная (по умолчанию), светлая, тёмная; хранение в `localStorage`, класс `dark` на `html`. |
| Язык | Заглушка (одна локаль); в планах — выбор языка при появлении переводов. |
| Регион и цели | Часовой пояс (`features/set-timezone`), дневная цель (`features/set-daily-goal`). |
| Данные | Отдельные действия: очистка IndexedDB (подходы и цель), сброс `localStorage` (тема, таймзона, быстрые кнопки), «очистить всё» с перезагрузкой страницы. Подтверждение через `AlertDialog`. |

### Дневная цель (детали)

| Аспект | Описание |
|--------|----------|
| Ответственность | Ввод целевого числа повторений в день, сохранение в `meta` (IndexedDB); сброс цели. |
| Поведение | Прогресс к цели отображается в **DayProgress** на экране дня. |

## Экран статистики

Состав: агрегаты, графики по дням, heatmap (`widgets/stats`). Дневная цель и часовой пояс настраиваются в **Настройках** (`/settings`).

### Блок totals

| Аспект | Описание |
|--------|----------|
| Ответственность | Всего повторений за всё время; опционально всего подходов. |
| Поведение | Читает производные `Stats` из store. |

### Блок averages

| Аспект | Описание |
|--------|----------|
| Ответственность | Среднее повторений на **активный** день; при отсутствии дней — «—». |
| Поведение | Не делить на календарные дни без записей. |

### Best day

| Аспект | Описание |
|--------|----------|
| Ответственность | День с максимальной суммой повторений; показать дату и число. |
| Поведение | При равенстве — выбрать одну детерминированно (например, более ранняя дата). |

### Графики динамики

| Аспект | Описание |
|--------|----------|
| Ответственность | Два столбчатых графика за выбранный период (**7** или **30** последних календарных дней, включая сегодня): сумма повторений по дням и число подходов по дням. |
| Поведение | Пустые дни — нули на графике; подсказки по дате. |

### Heatmap

| Аспект | Описание |
|--------|----------|
| Ответственность | Сетка «недели × дни недели» (последние 26 недель), интенсивность по сумме `reps` за день; подсказки по дате и объёму. |
| Поведение | Ячейки будущих дней (после текущего календарного дня) без данных; легенда «меньше / больше». |

## Гидрация и первый кадр

- Пока данные из IndexedDB не загружены, основной контент заменён **скелетонами**, близкими к реальной сетке карточек (день и статистика), чтобы уменьшить layout shift.
- После `hydrated === true` контент слегка **проявляется** (например `fade-in` / лёгкий `translate`), без обязательной motion-библиотеки.

## Уведомления (toasts)

- Глобальный **Toaster** (Sonner) в провайдерах приложения; действия «Отменить» после добавления/удаления подхода с ограничением по времени (стандартное поведение библиотеки).

## Переиспользование UI-kit

- Кнопки, карточки, прогресс: `@/components/ui/*` (Button, Card, Separator и т.д.).
- Тема: переключатель в настройках (`shared/lib/theme`: системная / светлая / тёмная), опционально `features/theme-toggle` и токены Tailwind.

## i18n

- Все пользовательские строки — через колоцированные `translations.ts` в слайсах + `shared/i18n` для общих меток (отмена, ошибки).
