# UI спецификация

## Навигация (MVP)

- Два основных раздела: **Главная** (лог за сегодня + быстрый ввод) и **Статистика**.
- Переключение: нижняя навигация или верхние табы (реализация на усмотрение; предпочтение — крупные зоны нажатия для скорости).

## Главный экран

Состав: **QuickAddPanel**, **DaySetsList**, **DayProgress** (возможна композиция в `widgets/main-screen`).

### QuickAddPanel

| Аспект | Описание |
|--------|----------|
| Ответственность | Минимум шагов для добавления подхода; пресеты и повтор последнего. |
| Содержимое | Кнопки **+10**, **+20** (значения из конфига), кнопка **«Как в прошлый раз»** / Repeat last. |
| Поведение | Тап по +N вызывает `addSet` с `reps: N` для типа по умолчанию. Repeat last: взять `reps` последнего подхода за **сегодня** для типа по умолчанию; если сегодня пусто — последний глобально для этого типа; если истории нет — кнопка disabled или toast «нет предыдущего». |
| Edge | Debounce/loading state на кнопках 150–300 ms при необходимости, чтобы отсечь двойные тапы. |

### Список подходов за сегодня (DaySetsList)

| Аспект | Описание |
|--------|----------|
| Ответственность | Показать все `Set` за текущий `dayKey`. |
| Отображение | Время (локальное) или порядковый номер; число повторений; опционально иконка типа (MVP — один тип). |
| Поведение | Свайп или кнопка «удалить» на строке → `removeSet(id)` с подтверждением опционально (для скорости MVP — undo toast предпочтительнее модалки). |
| Пустое состояние | Короткий текст + те же быстрые кнопки в фокусе. |

### Дневной прогресс (DayProgress)

| Аспект | Описание |
|--------|----------|
| Ответственность | Сумма `reps` за день; при наличии **Goal** — прогресс-бар или fraction «35 / 50». |
| Поведение | Обновляется синхронно после мутации store. |

## Экран статистики

Состав: агрегаты + **задел под heatmap** (`widgets/stats`).

### Блок totals

| Аспект | Описание |
|--------|----------|
| Ответственность | Всего повторений за всё время; опционально всего подходов. |
| Поведение | Читает производные `Stats` из store. |

### Блок averages

| Аспект | Описание |
|--------|----------|
| Ответственность | Среднее повторений на **активный** день; при отсутствии дней — «—». |
| Поведение | Не делить на календарные дни без записей. |

### Best day

| Аспект | Описание |
|--------|----------|
| Ответственность | День с максимальной суммой повторений; показать дату и число. |
| Поведение | При равенстве — выбрать одну детерминированно (например, более ранняя дата). |

### Heatmap (задел)

| Аспект | Описание |
|--------|----------|
| Ответственность | Визуализация активности по дням (как GitHub contributions). |
| MVP | Заглушка: текст «Скоро» или простая сетка без интерактива; данные готовить через `dayKey` агрегации. |

## Переиспользование UI-kit

- Кнопки, карточки, прогресс: `@/components/ui/*` (Button, Card, Separator и т.д.).
- Тема: существующий `features/theme-toggle` и токены Tailwind.

## i18n

- Все пользовательские строки — через колоцированные `translations.ts` в слайсах + `shared/i18n` для общих меток (отмена, ошибки).
