# UI спецификация

## Навигация (MVP)

- Четыре пункта: **Главная** (`/`), **День** (`/day/today` — календарь и лог за выбранный день), **Статистика**, **Настройки**.
- Переключение: **нижняя навигация** на узких экранах (`lg` ниже); на **`lg` и шире** — фиксированная **левая колонка** (~64 tailwind units), нижняя панель скрыта. Контент: `mx-auto`, `max-w-3xl` (статистика до `max-w-4xl`), отступы `px-4 sm:px-6`.
- **Главная** `/`: сводка за сегодня, быстрый ввод, список активных типов с переходом в карточку упражнения.
- **Маршруты дня:** `/day/today`, `/day/yesterday`, `/day/YYYY-MM-DD` — `widgets/main-screen` (**DayScreen**).
- **Карточка упражнения:** `/exercises/:exerciseId` (UUID) и создание `/exercises/new` — ленивый чанк; редактирование имени/иконки/цвета, архив, ссылка на `/stats/exercise/:id`.
- **Статистика:** `/stats`, `/stats/exercise/:exerciseId` — ленивые чанки + `Suspense`.
- **Настройки:** `/settings` — ленивый чанк. Старый путь `/settings/exercises` редиректит на `/`.

## Навигация по дням (DayNavigation)

| Аспект | Описание |
|--------|----------|
| Ответственность | Переход к предыдущему/следующему дню; выбор даты кликом по **заголовку даты** — Popover + календарь shadcn (`Calendar` + `react-day-picker`), чтобы одинаково работало на десктопе и в тач-интерфейсе. |
| Календарь | У дат, в которые есть хотя бы одна запись (по `dayKey` в store), под числом показывается **точка**; пустые дни без точки. |
| Поведение | Следующий день недоступен, если он позже сегодня. Переход на главную — пункт «Главная»; на сегодняшний день в календаре — пункт «День». |

## Главная (`/`)

Виджет `widgets/home-screen` (**HomeScreen**): краткая карточка «Сегодня» (число подходов и сумма повторов с подписью о смешении типов), ссылка «День и календарь» → `/day/today`, **ExerciseTypeSelect**, **QuickAddPanel** только для **сегодняшнего** `dayKey`, список активных упражнений с цифрами за сегодня (тап по строке — выбор preferred), кнопка перехода в `/exercises/:id`, кнопка «Добавить упражнение» → `/exercises/new`.

## Экран дня (`/day/:dayKey`)

Состав: **DayNavigation**, **DayProgress**, **ExerciseTypeSelect**, **QuickAddPanel**, **DaySetsList** (`widgets/main-screen`, **DayScreen**).

### Выбор типа для записи (`features/select-exercise`)

| Аспект | Описание |
|--------|----------|
| Ответственность | Задать `preferredExerciseTypeId` для новых подходов и для «повторить последний»; значение в `localStorage`. |
| Поведение | **Не** фильтрует список подходов и статистику — все типы видны в общем логе. В списке только **активные** типы из store. |

### QuickAddPanel

| Аспект | Описание |
|--------|----------|
| Ответственность | Минимум шагов для добавления подхода; пресеты из конфига, **пользовательские быстрые значения** (localStorage), поле своего числа в одном ряду с кнопками, повтор последнего. |
| Содержимое | Кнопки **+10**, **+20**; **поле ввода** в стиле кнопки (outline) — Enter / «ввод» на мобильной клавиатуре добавляет подход; после успешного ввода число сохраняется как **быстрая кнопка** (кроме совпадений с дефолтными пресетами), не более **5** штук в `localStorage`; при добавлении шестого **вытесняется** самое раннее сохранённое (FIFO). Кнопка **«Как в прошлый раз»**. Пользовательские кнопки можно **удалить** (иконка). |
| Поведение | Тап по +N вызывает `addSet` с `reps: N`, **`dayKey`** и типом из **preferred** в store. После успешного добавления — **тост с «Отменить»**. Repeat last: последний подход за **этот день** для **выбранного типа**; если в дне пусто — последний глобально для этого типа; если истории нет — кнопка без эффекта. Если **нет активных типов** — подсказка со ссылкой на `/exercises/new`. Для **будущего дня** — отдельная подсказка (`dayAllowsLogging` vs `canAddSet`). |
| Edge | Debounce/loading state на кнопках 150–300 ms при необходимости, чтобы отсечь двойные тапы. |

### Список подходов за день (DaySetsList)

| Аспект | Описание |
|--------|----------|
| Ответственность | Показать **все** `Set` за текущий `dayKey` (все `exerciseTypeId`). |
| Отображение | Иконка и короткое название типа; число повторений; время (локальное). |
| Поведение | Кнопка «удалить» на строке → `removeSet(id)`; после удаления — **тост «Отменить»** (`restoreSet`). |
| Пустое состояние | Короткий текст + быстрые кнопки в фокусе. |

### Дневной прогресс (DayProgress)

| Аспект | Описание |
|--------|----------|
| Ответственность | По каждому типу, у которого за день есть повторения **или** задана дневная цель: строка с суммой по типу; при цели — дробь и **Progress** только для этого типа. Отдельно — число **записей** подходов за день (строки в логе). |
| Поведение | Не смешивать повторения разных упражнений в одну цель без подписи. Синхронно с store. |

## Экран настроек

Маршрут `/settings`, виджет `widgets/settings-screen`.

| Блок | Описание |
|------|----------|
| Тема | Режимы: системная (по умолчанию), светлая, тёмная; хранение в `localStorage`, класс `dark` на `html`. |
| Язык | Заглушка (одна локаль); в планах — выбор языка при появлении переводов. |
| Регион и цели | Текст со ссылкой на **главную** (каталог упражнений перенесён туда и в `/exercises/:id`); часовой пояс (`features/set-timezone`); дневная цель (`features/set-daily-goal`). |
| Данные | Отдельные действия: очистка IndexedDB (подходы и цель), сброс `localStorage` (тема, таймзона, быстрые кнопки), «очистить всё» с перезагрузкой страницы. Подтверждение через `AlertDialog`. |

### Дневная цель (детали)

| Аспект | Описание |
|--------|----------|
| Ответственность | Ввод целевого числа повторений в день **для выбранного типа упражнения**; хранение в `meta` IndexedDB (`goalsByExerciseTypeId`); сброс цели для выбранного типа. |
| Поведение | Прогресс к цели — в **DayProgress** отдельно по каждому типу с целью. В селекторе типа цели только **активные** упражнения. |

## Карточка упражнения (`/exercises/:exerciseId`, `/exercises/new`)

Форма полей в `features/manage-exercises` (**ExerciseTypeEditorFields**); сохранение через store.

| Аспект | Описание |
|--------|----------|
| Ответственность | Имя, иконка из пресетов, цвет пресет или свой HEX (+ `input type="color"`). **В архив** / **Вернуть**. Ссылка на `/stats/exercise/:id`. Краткие метрики за сегодня и за всё время (опционально на странице редактирования). |
| Поведение | `putExerciseType` в IndexedDB; после создания — редирект на `/exercises/:uuid`. |

## Экран статистики (`/stats`)

Состав: компактный список **ссылок по всем типам** из каталога (включая архивные) → `/stats/exercise/:id`; блок **общей сводки**; **один** обзорный график (сумма повторов + линия подходов по всем типам); heatmap по всем типам (`widgets/stats`).

### Список «По упражнениям»

| Аспект | Описание |
|--------|----------|
| Ответственность | Строки-ссылки: имя, иконка, метка «в архиве» при необходимости; детальные метрики и графики только на странице типа. |

### Блок totals

| Аспект | Описание |
|--------|----------|
| Ответственность | Сводка по **всем** подходам: сумма повторений (с подсказкой о смешении), всего подходов, дней с любой активностью, среднее за активный день. |
| Поведение | `computeStats` по полному массиву `sets`. |

### Блок averages

| Аспект | Описание |
|--------|----------|
| Ответственность | Среднее повторений на **активный** день; при отсутствии дней — «—». |
| Поведение | Не делить на календарные дни без записей. |

### Best day

| Аспект | Описание |
|--------|----------|
| Ответственность | День с максимальной **суммой повторений по всем типам**; подпись, что это смешанный объём. |
| Поведение | При равенстве — более ранняя дата (`computeStats`). |

### Графики динамики (сводка)

| Аспект | Описание |
|--------|----------|
| Ответственность | За **7** или **30** дней: **столбцы** суммарных повторений по дням (все типы); **линия** числа подходов за день. |
| Поведение | Подсказка, что столбец — сумма по всем упражнениям за день. |

## Статистика по одному типу (`/stats/exercise/:exerciseId`)

| Аспект | Описание |
|--------|----------|
| Ответственность | Заголовок с именем/иконкой/цветом типа; карточки `computeStatsForExerciseType`; тот же виджет тренда на **отфильтрованных** `sets`; heatmap с фильтром по одному `exerciseTypeId`. |
| Поведение | Доступно и для **архивных** типов; неверный/отсутствующий UUID — сообщение и ссылка назад на `/stats`. |

### Heatmap

| Аспект | Описание |
|--------|----------|
| Ответственность | Сетка «недели × дни недели» (26 недель); интенсивность ячейки — **сумма** `reps` за день по **всем** типам; в tooltip при нескольких типах — разбивка по типам. |
| Поведение | Ячейки будущих дней без данных; легенда «меньше / больше». |

## Гидрация и первый кадр

- Пока данные из IndexedDB не загружены, основной контент заменён **скелетонами**, близкими к реальной сетке карточек (день и статистика), чтобы уменьшить layout shift.
- После `hydrated === true` контент слегка **проявляется** (например `fade-in` / лёгкий `translate`), без обязательной motion-библиотеки.

## Уведомления (toasts)

- Глобальный **Toaster** (Sonner) в провайдерах приложения; действия «Отменить» после добавления/удаления подхода с ограничением по времени (стандартное поведение библиотеки).

## Переиспользование UI-kit

- Кнопки, карточки, прогресс: `@/components/ui/*` (Button, Card, Separator и т.д.).
- Тема: переключатель в настройках (`shared/lib/theme`: системная / светлая / тёмная), опционально `features/theme-toggle` и токены Tailwind.

## i18n

- Все пользовательские строки — через колоцированные `translations.ts` в слайсах + `shared/i18n` для общих меток (отмена, ошибки).
