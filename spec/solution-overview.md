# Целевое решение — обзор

## Назначение

Локальное PWA-приложение для учёта силовых/повторных упражнений (в т.ч. отжиманий) с упором на **скорость записи** и простую статистику без бэкенда.

## Поток: открытие до логирования

1. Пользователь открывает приложение (онлайн не обязателен).
2. `app` монтируется, провайдеры (i18n, тема) активны.
3. Store вызывает `hydrate()`: `StorageAdapter` читает IndexedDB — **подходы** (`sets`), **каталог типов** (`exerciseTypes`), **цели** (`goals` в `meta`), плюс восстанавливается **таймзона** из предпочтений клиента.
4. **Главная** (`/`): после гидратации — **HomeTodayStatsCards** (сводка за сегодня, карточки по активным типам со ссылками, карточка «Добавить упражнение»), **ExerciseQuickAddBlock** (выбор типа кнопками-иконками + **QuickAddPanel**), при наличии архивных типов — **HomeArchivedExercisesSection** (**ArchivedExerciseCollapsible**). Ссылка «День и календарь» ведёт на `/day/today`.
5. **Экран дня** (`/day/:dayKey`): **DayNavigation**, **DayProgress**, **ExerciseQuickAddBlock**, **DaySetsList** — детальный лог и прогресс за выбранный день.
6. Пользователь нажимает действие быстрого ввода → feature `add-set` → `addSet` в store → запись в IndexedDB → UI обновляется сразу (целевой горизонт — < 2 с от намерения до появления записи).

## Основные сценарии

| Сценарий | Шаги |
|----------|------|
| Быстрый лог | Выбор типа (если несколько) → ввод числа и отправка (или шаги по черновику) → подход через store; на экране дня — строка в списке; на главной — обновление карточек «сегодня». |
| Повтор последнего | Не отображается в UI; может быть добавлен как отдельное действие (см. `spec/ui.md`). |
| Ошибка | Удаление строки / undo через toast — список и сумма синхронизированы с БД (`restoreSet`). |
| Смена дня | После полуночи (или при возврате на вкладку) пересчёт `dayKey` — главная и «сегодня» показывают новый день. |
| Статистика | Переход на `/stats` → чистые функции `computeStats` / виджеты → totals / average / best day; по типу — `/stats/exercise/:id`. |
| Резервная копия данных | `/settings` → «Экспортировать JSON» сохраняет снимок `sets`/`exerciseTypes`/`goals`/`meta`; «Импортировать JSON» валидирует файл, показывает сводку в диалоге и по подтверждению полностью восстанавливает данные в IndexedDB. |
| Удаление типа упражнения | Карточка `/exercises/:id` → подтверждение в диалоге → `deleteExerciseType` в store → `StorageAdapter.deleteExerciseType` (все подходы по типу, цель в `meta`, запись в `exerciseTypes`) → переход на главную. |
| Редактирование типа | `/exercises/:id/edit` → сохранение → карточка типа и toast об успехе. |

## Границы системы

- Данные остаются на устройстве; backup/restore выполняется локально через JSON-файл, без отправки на сервер.
- Один пользователь на профиль браузера (без аккаунта).
