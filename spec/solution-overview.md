# Целевое решение — обзор

## Назначение

Локальное PWA-приложение для учёта отжиманий с упором на **скорость записи** и простую статистику без бэкенда.

## Поток: открытие до логирования

1. Пользователь открывает приложение (онлайн не обязателен).
2. `app` монтируется, провайдеры (i18n, тема) активны.
3. Store вызывает `hydrate()`: `StorageAdapter` читает IndexedDB, заполняет подходы и цель.
4. Главная страница показывает **QuickAddPanel**, **DayProgress**, **DaySetsList** для текущего `dayKey`.
5. Пользователь нажимает, например, **+20** → feature `add-set` → `addSet` в store → запись в IndexedDB → UI обновляется **сразу** (цель — < 2 с от намерения до отображения новой строки).

## Основные сценарии

| Сценарий | Шаги |
|----------|------|
| Быстрый лог | Тап пресета → подход в списке, счётчик дня обновлён. |
| Повтор последнего | Тап repeat → тем же `reps`, что и в последнем релевантном подходе. |
| Ошибка | Удаление строки / undo — список и сумма синхронизированы с БД. |
| Смена дня | После полуночи (или при возврате на вкладку) пересчёт `dayKey` — экран показывает новый «сегодня». |
| Статистика | Переход на экран stats → `computeStats()` → totals / average / best day. |

## Границы системы

- Данные остаются на устройстве; резервное копирование — вне MVP (см. roadmap).
- Один пользователь на профиль браузера (без аккаунта).
